# My Drive (code name)

Premium CarPlay / Android Auto companion by Biolynk Technologies.
Start here: `CLAUDE.md` (rules), `docs/SPEC.md` (what v0 does), `docs/TASKS.md` (who does what).

- iOS: `cd ios && xcodegen && open MyDrive.xcodeproj` (MacBook)
- Android: `cd android && .\gradlew assembleDebug` (Windows PC)
- Car pictures: `tools/carrender/render.py` (Vertex AI, GCP credits)
